# 콘텐츠 작업 기본 규칙 (Content Rules)

본 규칙은 ALBA & BOSS 포털의 모든 콘텐츠(정책소식, 최신뉴스, 노무·세무 팁, 노무 Q&A, 추천영상, 법적 기준치 등) 수집·갱신·편집 작업 시 예외 없이 적용됩니다.

---

### 1. URL 및 리다이렉트 금지 규칙
- **임시 리다이렉트 주소 절대 사용 금지**: `vertexaisearch.cloud.google.com/grounding-api-redirect` 등의 프록시/임시 주소는 저장하거나 해석을 시도하지 않습니다.
- **사이트 메인 도메인 주소 저장 금지**: `moel.go.kr`, `hankyung.com` 등 사이트 대표 주소나 목록 페이지 링크는 절대 저장하지 않습니다. 모든 링크는 실제 사용자가 접근했을 때 특정 글 또는 특정 영상을 바로 볼 수 있는 **개별 페이지(Permanent URL)**여야 합니다.
- **10초 접속 타임아웃**: 모든 외부 URL 확인 요청은 10초 이내에 응답이 없으면 즉시 타임아웃 처리하고 건너뜁니다.
- **검증 불가 링크 추가 금지**: 실제 HTTP 요청 또는 브라우징을 통해 페이지 제목과 콘텐츠가 일치하는지 사전에 확인하지 못한 항목은 절대 추측으로 생성하여 추가하지 않습니다.

### 2. 코드 실행 및 스크립트 작성 규칙
- **인라인 코드 실행 금지**: 터미널에서 `node -e "..."` 와 같이 여러 줄의 인라인 코드를 실행하는 것을 금지합니다.
- **스크립트 파일 모듈화**: 필요한 작업이나 검증 로직은 반드시 `scripts/` 폴더에 `.js` 스크립트 파일로 작성한 후 `node scripts/파일명.js` 형태로 실행합니다.

### 3. 법적 기준치 및 데이터 일관성
- **기준치 파일 최우선 참조**: 최저임금, 주휴수당 산정 방식, 연장·야간·휴일 가산수당 배율, 5인 미만 사업장 적용 제외 규정, 4대보험 요율 등 모든 법적 기준치는 [`data/standards.json`](data/standards.json)에 기록된 검증된 값을 최우선 기준으로 사용합니다.
- **기준치 불일치 시 선행 조치**: 수집 대상 뉴스나 팁에서 `standards.json`과 다른 수치가 발견될 경우 임의로 반영하지 말고, 반드시 법령 고시와 공단을 재확인하는 기준치 검증 워크플로(`check-standards`)를 먼저 실행합니다.
- **저자 표기 통일**: 노무·세무 팁 등 자체 발행 실무 가이드의 저자(author)는 반드시 `"ALBA&BOSS 편집부"`로 통일합니다.

### 4. 저작권 및 공공데이터 준수
- **원문 무단 복제 금지**: 요약(summary, content, answer)은 원문을 그대로 복사·붙여넣지 않고 한두 문장의 알기 쉬운 표준어로 직접 재작성합니다.
- **공공누리 표시 확인**: 고용노동부, 근로복지공단 등 정부 공공기관 자료는 공공누리(제1유형 등) 표기 또는 공공저작물 개방 기준이 확인된 자료만 선별합니다.

### 5. 데이터 스키마 및 수량 제한
- **기존 데이터 스키마 엄수**: `data/news.json`, `data/articles.json`, `data/videos.json`, `data/tips.json`, `data/qna.json`, `data/board.json`, `data/standards.json`의 JSON 필드 구조를 임의로 변경하거나 누락하지 않습니다.
- **1회 갱신 수량 제한**: 1회 갱신 시 최대 5개(추천영상은 최대 3개)까지만 추가하며, 이미 등록된 중복 항목은 제외합니다.
- **단정적 표현 금지**: 노무 상담 및 Q&A 답변 시 개별 사실관계에 대한 단정("무조건 받을 수 있습니다")은 금지하며, 법령상 객관적 일반 기준만을 제시하고 전문가 상담 권고 문구를 유지합니다.

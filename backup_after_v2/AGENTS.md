## 정책 소식 수집 규칙

"정책 소식 갱신"이라고 하면 아래 절차를 수행한다.

### 대상 출처 (이 안에서만 찾을 것)
- 고용노동부 정책자료실·보도자료 (moel.go.kr)
- 최저임금위원회 (minimumwage.go.kr)
- 근로복지공단 (comwel.or.kr)
- 국민연금공단, 국민건강보험공단 요율·제도 공지

### 선별 기준
- 알바생, 단시간 근로자, 5인 미만 사업장 사장님에게 해당되는 것만
- 최저임금, 주휴수당, 근로계약, 4대보험 요율, 퇴직금,
  근로시간, 청년 고용지원 관련
- 최근 3개월 이내
- 이미 news.json에 있는 항목은 제외
- 한 번에 최대 5개

### 작성 규칙
- summary는 원문을 복사하지 말고 한 문장으로 직접 요약할 것
- title도 필요하면 줄여 쓰되 내용을 바꾸지 말 것
- url은 실제로 열리는 주소여야 함. 추측해서 만들지 말 것
- 공공누리 표시가 없는 자료는 넣지 말 것
- date는 원문 게시일

### 출력
data/news.json 배열 맨 앞에 추가하고,
추가한 항목을 제목·출처·링크 목록으로 보고할 것.
링크는 실제로 접속해서 열리는지 확인한 뒤 보고할 것.

## 노무 Q&A 규칙

"노무 Q&A 갱신"이라고 하면 아래 절차를 수행한다.

### 다룰 질문
알바생과 5인 미만 사업장 사장님이 실제로 검색하는 질문.
- 주휴수당 발생 요건, 결근·지각 시 처리
- 수습기간 감액 가능 여부
- 4대보험 가입 기준, 3.3% 공제와의 차이
- 퇴직금 발생 요건
- 근로계약서 미작성 시
- 연차 발생 기준
- 야간·연장·휴일 수당과 5인 미만 사업장

### 작성 규칙
- answer는 3~4문장. 결론을 첫 문장에 먼저 쓸 것
- 반드시 법령 조문이나 정부 공식 안내를 근거로 할 것
- 근거가 불확실하면 그 항목을 만들지 말 것. 추측 금지
- law에 근거 조문을 적을 것 (예: 근로기준법 제55조)
- source_url은 법령정보센터(law.go.kr) 또는
  고용노동부(moel.go.kr)의 실제로 열리는 주소
- 개별 사안에 대한 단정("당신은 받을 수 있습니다") 금지.
  일반 기준만 서술할 것
- 관련 계산기가 있으면 calculator_link에 내부 경로를 넣을 것
  (급여계산기 /payroll, 근무표 /scheduler)
- 한 번에 최대 5개, 이미 있는 질문은 제외

### 출력
data/qna.json 배열에 추가하고,
추가한 질문과 근거 조문을 목록으로 보고할 것.
source_url이 실제로 열리는지 확인한 뒤 보고할 것.
